# Security policy

The current `v1.2.x` release line receives security fixes. Older lines may be
updated when a vulnerability also affects them, but no backport is promised.

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Nickgonzales76017/bonfyre-agent-trace-verifier/security/advisories/new).
Do not place credentials, private traces, exploit details, or customer data in
a public issue. An initial acknowledgement is targeted within seven days.
